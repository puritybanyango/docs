title: "Scanned Devices API: Edge AI Classification Results"
sidebarTitle: "Scanned Devices"
description: "Store and query AI classification events from edge hardware. Each record represents a component identified on the sorting line and linked to a batch."
---

The `/api/scanned-devices` endpoints receive and serve classification events generated by the Raspberry Pi 5 edge AI system. Each scanned-device record represents a single component identified on the sorting line — a PCB or a battery — linked to a specific batch. All requests require an `Authorization: Bearer TOKEN` header obtained from [`POST /auth/login`](/api/auth#post-authlogin).

<Note>
  These records are typically created automatically by the edge hardware during a sorting session. Manual POST requests are used for edge device integration testing — for example, to verify that your Raspberry Pi unit can authenticate and write classification data to the API before a live sorting run.
</Note>

---

## POST /api/scanned-devices

Submit a new classification result from the edge device. The edge hardware calls this endpoint each time the computer vision model identifies a component on the sorting line.

### Request body

<ParamField body="batch_id" type="string" required>
  The ID of the active batch this classification result belongs to.
</ParamField>

<ParamField body="component_type" type="string" required>
  The type of component identified by the model. Must be one of:
  - `"pcb"` — printed circuit board
  - `"battery"` — battery cell or pack
</ParamField>

<ParamField body="confidence" type="number">
  The model's confidence score for this classification, expressed as a decimal between `0` and `1`. A value of `0.97` means the model is 97% confident. Omit this field if the edge device does not expose a confidence score.
</ParamField>

### Example request

```bash
curl -X POST https://eloop-api.herokuapp.com/api/scanned-devices \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "batch_id": "bat_01HXYZ654321",
    "component_type": "pcb",
    "confidence": 0.97
  }'
```

### Example response

```json
{
  "id": "sd_01HXYZ987654",
  "batch_id": "bat_01HXYZ654321",
  "component_type": "pcb",
  "confidence": 0.97,
  "created_at": "2024-06-01T11:02:44Z"
}
```

### Response fields

<ResponseField name="id" type="string">
  Unique identifier for this classification event record.
</ResponseField>

<ResponseField name="batch_id" type="string">
  The batch this classification event is associated with.
</ResponseField>

<ResponseField name="component_type" type="string">
  The component type identified: `"pcb"` or `"battery"`.
</ResponseField>

<ResponseField name="confidence" type="number">
  The model's confidence score at inference time, if provided.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp recording when this classification event was persisted.
</ResponseField>

## GET /api/scanned-devices

Retrieve all scanned device records across your company account. Results are paginated.

### Query parameters

<ParamField query="page" type="integer" default="1">
  The page number to retrieve. Starts at `1`.
</ParamField>

<ParamField query="limit" type="integer" default="20">
  The number of records to return per page.
</ParamField>

### Example request

```bash
curl -X GET "https://eloop-api.herokuapp.com/api/scanned-devices?page=1&limit=20" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### Example response

```json
[
  {
    "id": "sd_01HXYZ987654",
    "batch_id": "bat_01HXYZ654321",
    "component_type": "pcb",
    "confidence": 0.97,
    "created_at": "2024-06-01T11:02:44Z"
  },
  {
    "id": "sd_01HXYZ987655",
    "batch_id": "bat_01HXYZ654321",
    "component_type": "battery",
    "confidence": 0.91,
    "created_at": "2024-06-01T11:03:10Z"
  }
]
```

## PATCH /api/scanned-devices/batch/\{batch_id\}

Update classification fields across all scanned device records belonging to a batch. Send only the fields you want to change — all records in the batch will be updated with the provided values.

### Path parameters

<ParamField path="batch_id" type="string" required>
  The unique identifier of the batch whose scanned device records you want to update.
</ParamField>

### Request body

<ParamField body="component_type" type="string">
  Updated component type to apply across all records in the batch. Must be `"pcb"` or `"battery"`.
</ParamField>

<ParamField body="confidence" type="number">
  Updated confidence score to apply across all records in the batch.
</ParamField>

### Example request

```bash
curl -X PATCH https://eloop-api.herokuapp.com/api/scanned-devices/batch/bat_01HXYZ654321 \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "confidence": 0.95
  }'
```

### Example response

```json
{
  "batch_id": "bat_01HXYZ654321",
  "updated_count": 3,
  "message": "All scanned device records for batch bat_01HXYZ654321 have been updated."
}
```

## DELETE /api/scanned-devices/batch/\{batch_id\}

Delete all scanned device records associated with a specific batch.

<Warning>
  This action removes **all** classification data for the specified batch and cannot be undone. Deleting scanned device records before finalizing a batch results in an empty component set, which prevents accurate material valuation. Confirm the correct `batch_id` before proceeding.
</Warning>

### Path parameters

<ParamField path="batch_id" type="string" required>
  The unique identifier of the batch whose classification records you want to permanently delete.
</ParamField>

### Example request

```bash
curl -X DELETE https://eloop-api.herokuapp.com/api/scanned-devices/batch/bat_01HXYZ654321 \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### Example response

```json
{
  "batch_id": "bat_01HXYZ654321",
  "deleted_count": 3,
  "message": "All scanned device records for batch bat_01HXYZ654321 have been deleted."
}
```
