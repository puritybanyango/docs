The `/api/batches` endpoints manage the full lifecycle of e-waste lots — from the start of a sorting session through automated valuation, Digital Showroom listing, booking, and completion. Each batch aggregates the scanned component data from a single sorting run. All requests require an `Authorization: Bearer TOKEN` header obtained from [`POST /auth/login`](/api/auth#post-authlogin).

A batch moves through four sequential stages:

```text
In Progress → Listed → Booked → Completed
```

Create a batch to open a sorting session, use `PATCH` to finalize and value it once sorting ends, then use `PUT` to advance its status as it moves through the marketplace.

---

## POST /api/batches

Create a new batch and open a sorting session. Call this endpoint when an operator begins processing a new e-waste lot on the sorting line. The Raspberry Pi 5 edge hardware will associate all subsequent classification events with this batch.

### Request body

<ParamField body="user_id" type="string" required>
  The unique identifier of the recycling center operator starting this sorting session.
</ParamField>

### Example request

```bash
curl -X POST https://eloop-api.herokuapp.com/api/batches \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "user_07cd3e9f1a2bgh"
  }'
```

### Example response

```json
{
  "id": "bat_01HXYZ654321",
  "status": "in_progress",
  "user_id": "user_07cd3e9f1a2bgh",
  "created_at": "2024-06-01T11:00:00Z"
}
```

### Response fields

<ResponseField name="id" type="string">
  Unique identifier for the newly created batch. Pass this to the Raspberry Pi 5 unit so it can tag all classification events to this session.
</ResponseField>

<ResponseField name="status" type="string">
  The initial batch status. Always `"in_progress"` on creation.
</ResponseField>

<ResponseField name="user_id" type="string">
  The operator who opened this sorting session.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp recording when the batch was created.
</ResponseField>

## GET /api/batches/\{batch_id\}

Retrieve the valuation scores, component summary, and current status for a specific batch.

### Path parameters

<ParamField path="batch_id" type="string" required>
  The unique identifier of the batch to retrieve.
</ParamField>

### Example request

```bash
curl -X GET https://eloop-api.herokuapp.com/api/batches/bat_01HXYZ654321 \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### Example response

```json
{
  "id": "bat_01HXYZ654321",
  "status": "listed",
  "value_tier": "HIGH",
  "component_count": 42,
  "user_id": "user_07cd3e9f1a2bgh",
  "created_at": "2024-06-01T11:00:00Z",
  "updated_at": "2024-06-01T11:45:00Z"
}
```

### Response fields

<ResponseField name="id" type="string">
  Unique identifier for the batch.
</ResponseField>

<ResponseField name="status" type="string">
  Current lifecycle stage: `"in_progress"`, `"listed"`, `"booked"`, or `"completed"`.
</ResponseField>

<ResponseField name="value_tier" type="string">
  The automated material valuation tier assigned when the batch was finalized. One of `"HIGH"`, `"MEDIUM"`, or `"LOW"`. Returns `null` for batches still `in_progress`.
</ResponseField>

<ResponseField name="component_count" type="integer">
  Total number of components identified by the edge AI during the sorting session.
</ResponseField>

<ResponseField name="user_id" type="string">
  The operator who created this batch.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp recording when the batch was created.
</ResponseField>

<ResponseField name="updated_at" type="string">
  ISO 8601 timestamp of the most recent update to this batch.
</ResponseField>

## PATCH /api/batches/\{batch_id\}

Finalize a batch once the sorting session is complete. This triggers automated material valuation — eLoop analyzes the aggregated component data from the edge AI, assigns a value tier (`HIGH`, `MEDIUM`, or `LOW`), and transitions the batch status from `in_progress` to `listed`, making it visible in the Digital Showroom.

<Note>
  This is the **"Finish Batch"** action in the Operator PWA. Ensure the sorting session is fully complete and the Raspberry Pi 5 has submitted all classification events before calling this endpoint. Finalizing a batch with incomplete scan data may result in a lower value tier than expected.
</Note>

### Path parameters

<ParamField path="batch_id" type="string" required>
  The unique identifier of the `in_progress` batch to finalize.
</ParamField>

### Example request

```bash
curl -X PATCH https://eloop-api.herokuapp.com/api/batches/bat_01HXYZ654321 \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### Example response

```json
{
  "id": "bat_01HXYZ654321",
  "status": "listed",
  "value_tier": "HIGH",
  "component_count": 42,
  "user_id": "user_07cd3e9f1a2bgh",
  "created_at": "2024-06-01T11:00:00Z",
  "updated_at": "2024-06-01T11:45:00Z"
}
```

## PUT /api/batches/\{batch_id\}

Transition a batch through its post-listing lifecycle stages. Use this endpoint to advance a batch from `listed` to `booked` when a buyer's booking is confirmed, and from `booked` to `completed` once the physical transfer of materials is finalized.

### Path parameters

<ParamField path="batch_id" type="string" required>
  The unique identifier of the batch whose status you want to transition.
</ParamField>

### Request body

<ParamField body="status" type="string" required>
  The target lifecycle stage. Must be one of:
  - `"listed"` — batch is visible in the Digital Showroom
  - `"booked"` — batch has an active confirmed booking
  - `"completed"` — materials have been physically transferred to the buyer
</ParamField>

### Example request

```bash
curl -X PUT https://eloop-api.herokuapp.com/api/batches/bat_01HXYZ654321 \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "status": "completed"
  }'
```

### Example response

```json
{
  "id": "bat_01HXYZ654321",
  "status": "completed",
  "value_tier": "HIGH",
  "component_count": 42,
  "user_id": "user_07cd3e9f1a2bgh",
  "created_at": "2024-06-01T11:00:00Z",
  "updated_at": "2024-06-03T16:10:00Z"
}
```

## DELETE /api/batches/\{batch_id\}/

Delete a batch record from the system.

<Warning>
  Only delete batches that are still in `in_progress` status. Deleting a `listed` batch removes it from the Digital Showroom immediately, which may disrupt active buyer interest. Deleting a `booked` batch will orphan any confirmed booking against it. If you need to cancel a listed or booked batch, transition it to the appropriate status using `PUT` instead.
</Warning>

### Path parameters

<ParamField path="batch_id" type="string" required>
  The unique identifier of the batch to delete.
</ParamField>

### Example request

```bash
curl -X DELETE https://eloop-api.herokuapp.com/api/batches/bat_01HXYZ654321/ \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### Example response

```json
{
  "message": "Batch bat_01HXYZ654321 has been deleted."
}
```
